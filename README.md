# Калькулятор стресса
### 1. Краткое описание проекта
"Калькулятор стресса" — десктопное приложение на Python с графическим интерфейсом (Tkinter), предназначенное для комплексной оценки уровня стресса пользователя на основе анализа четырёх ключевых факторов:

- Сон
- Питание
- Физическая активность
- Эмоциональное состояние

Приложение объединяет математические модели для каждого модуля и формирует единый индекс стресса с визуализацией данных (Matplotlib) и персонализированными рекомендациями.

### 2. Архитектура приложения
Программа состоит из нескольких независимых модулей, каждый из которых отвечает за свою функцию:

- Модули расчёта для каждой категории 
- Модуль визуализации результатов
- Модуль генерации и проверки лицензионных ключей
- Главный модуль управления интерфейсом и навигацией

**2.1 Модули расчёта** 
Каждый модуль содержит математическую модель, преобразующую входные данные пользователя в количественную оценку стресса (от 0 до 10 баллов).

Сон: рассчитывает длительность, дефицит, циркадное рассогласование, социальный джетлаг и нестабильность режима.

Питание: учитывает качество рациона, перекусы, потребление воды, кофеина, алкоголя, а также защитные факторы (ферментированные продукты, зелёный чай, магний).

Активность: моделирует влияние рабочих часов, типа деятельности, ночных смен и физических упражнений.

Эмоции: оценивает негативные эмоции (грусть, тревога, гнев), позитивные (радость) и социальное взаимодействие.

**2.2 Модуль интеграции**
Объединяет результаты четырёх модулей в единый показатель с учётом межфакторных взаимодействий (сон ↔ эмоции, активность ↔ питание и т.д.). Общее усиление стресса ограничено 30%.

**2.3 Система защиты (генерация ключей)**
Для премиум-доступа реализована система генерации уникальных ключей активации на основе матричных преобразований.

Алгоритм включает прямое преобразование со случайным смещением и обратное преобразование через обратную матрицу

### 3. Реализованный функционал
Приложение поддерживает два режима работы: бесплатный и премиум.

**3.1 Бесплатный режим**
- Ввод данных по каждой из четырёх категорий
- Расчёт индивидуальных показателей
- Визуализация результатов в виде графиков
- Базовые текстовые рекомендации

**3.2 Премиум-режим**
- Полный доступ ко всем результатам
- Сводный график общего уровня стресса
- Расширенная аналитика
- Активация через лицензионный ключ

### 4. Интерфейс и навигация
Интерфейс реализован с помощью библиотеки Tkinter и построен по принципу интуитивной навигации:

- Главное меню с выбором бесплатного или премиум-режима
- Четыре раздела для ввода данных ("Сон", "Питание", "Активность", "Эмоции")
- Кнопка "Назад" для возврата в главное меню
- Кнопка "Сохранить" для фиксации введённых данных
- Кнопка "Показать графики" для визуализации
- Цветовая индикация результатов: зелёный (норма), оранжевый (средний), красный (высокий уровень стресса)
